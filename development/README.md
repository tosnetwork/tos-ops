# Development network

Settings for the shared development network: a multi-host network that the team
runs between the single-host local network (`local/`) and production
(`production/`). Nothing is here yet.

Add here, as they are created:

- service units and their overrides;
- install and control scripts;
- operating notes.

Use the same subdirectory layout as `local/`: `scripts/`, `systemd/`, `tests/`
and a `README.md`. Keys, seeds, tokens and certificates stay out of the
repository.
